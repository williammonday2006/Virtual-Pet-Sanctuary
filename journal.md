# Phase 1

In this phase, I created a Pet class with a constructor and a describe() method. A class is a blueprint for creating pets, while an instance is an individual pet with its own name and type.

# Phase 2

In this phase, I added a hunger property and a feed() method to the Pet class. I connected the method to an HTML button using an event listener and updated the hunger display with textContent. I found that connecting the button to the JavaScript was straightforward.

# Phase 3

In this phase, I created a dynamic sanctuary where users can add pets with different names and types. Each pet has its own card, hunger level, and Feed button. The Pet class makes managing multiple pets easier because each instance stores its own data and uses the same methods.
